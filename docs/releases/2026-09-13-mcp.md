# MCP access and existing agent integration

This release adds a standard MCP entrance to Ops Center's operational API and a standard MCP client to the existing Ops Floor agent runtime. Agents, conversations, delegation and the Ops Floor UI continue to operate.

- A reviewed catalog of 113 tools spans inventory, Traffic Map, monitoring, logs, patching, security, containers, Ansible, cluster and AI operations.
- OAuth with PKCE S256, exact redirects, resource-bound tokens, consented tool subsets, current-role enforcement, rotating refresh tokens and immediate grant revocation.
- MCP access administration for external clients and explicit agent/user authorizations, with no default grants.
- Human review of exact write arguments, encrypted pending payloads, idempotency and one-time execution claims.
- Metadata-only MCP audit, bounded calls and results, and automatic retention.
- Policy/capability resources, incident and maintenance prompts, and a request-status tool.
- Synthetic browser fixtures and isolated PostgreSQL/standard-SDK integration tests.

Upgrade the API, frontend and AI worker and apply migration **0042**. Configure the canonical HTTPS MCP URL and proxy routes before enabling MCP in the UI. No existing Ops Floor agent gains permissions automatically. See [MCP setup, permissions and limits](../mcp.md) and [the complete catalog](../mcp-tools.md).

Validation: **326 Python tests**, **75 browser cases**, frontend build/lint, isolated migration round-trip, and dependency audits. See [validation notes](../validation.md).
